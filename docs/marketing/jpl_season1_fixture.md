## Host runbook

1. **Create tournament** (admin): title e.g. `Judgement Premier League — Season 1`, status **Live**.
2. **Each Matchday**, open **three rooms** and attach each to that tournament:
   - Room 1 → Big Six (max players 6)
   - Room 2 → Orange (max players 4)
   - Room 3 → Blue (max players 4)
3. Seat only the named players for that table; **no guest substitutes**.
4. Start all three tables in the same sitting when the squad is ready.
5. If someone is absent, **reschedule that table** — do not silently replace.
6. Standings accumulate on the app **Tournament** tab (same medal math as Top players).
7. After Matchday 6, champion = top of tournament standings; optionally publish the pair heat-map from this script’s JSON.
